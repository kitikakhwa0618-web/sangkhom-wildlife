# สัตว์ป่าอำเภอสร้างคอม

เว็บสมุดบันทึกสัตว์ป่าอำเภอสร้างคอม จังหวัดอุดรธานี เป็นเว็บแบบ static (HTML, CSS, JavaScript ล้วน) ไม่ต้องติดตั้งหรือ build อะไร ใช้กับ GitHub Pages ได้ทันที

## โครงสร้างไฟล์

```
index.html   หน้าเว็บ
style.css    การจัดหน้าตา (รองรับโหมดมืดและมือถือ)
data.js      ข้อมูลสัตว์ทั้งหมด (แก้ไฟล์นี้เพื่อเพิ่มหรือแก้สัตว์)
script.js    ระบบค้นหา กรองกลุ่ม และหน้าต่างรายละเอียด
images/      (สร้างเอง) โฟลเดอร์ใส่รูปสัตว์
```

## อัปขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `sangkhom-wildlife` (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปที่ branch `main`
3. ไปที่ **Settings → Pages**
4. ที่ **Build and deployment** เลือก **Source: Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/sangkhom-wildlife/`

ลิงก์ตรงไปยังสัตว์แต่ละชนิดทำได้โดยต่อ `#id` เช่น `.../#cattle-egret`

## เพิ่มสัตว์ชนิดใหม่

เปิด `data.js` คัดลอกก้อน `{ ... }` หนึ่งก้อน วางต่อท้าย แล้วแก้ข้อมูล ค่า `id` ต้องไม่ซ้ำและใช้ตัวอักษรอังกฤษพิมพ์เล็กคั่นด้วยขีด

## ใส่รูปจริง

1. สร้างโฟลเดอร์ `images/` แล้วใส่รูป เช่น `images/cattle-egret.jpg`
2. ใน `data.js` ใส่ `image: "images/cattle-egret.jpg"` ถ้าเว้นว่างไว้ จะแสดงอีโมจิแทน

ควรใช้รูปที่ถ่ายเองหรือได้รับอนุญาต และระบุชื่อผู้ถ่ายภาพ

## หมายเหตุเรื่องข้อมูล

ข้อมูลชุดแรกเป็นข้อมูลทั่วไปของสัตว์ที่พบในภาคตะวันออกเฉียงเหนือ ยังไม่ได้ยืนยันกับบันทึกการพบเห็นในอำเภอสร้างคอมโดยตรง ควรให้คนในพื้นที่หรือเจ้าหน้าที่ตรวจสอบก่อนเผยแพร่เป็นทางการ และตรวจสถานะ IUCN ล่าสุดที่ https://www.iucnredlist.org
